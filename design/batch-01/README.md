# Первый батч · 01–05

Figma Slides: https://www.figma.com/slides/lNMybuIlB1rY2xxwmzgyJ6

Рабочая реализация первых пяти слайдов `slides.md` для обсуждения визуальной системы. Основное направление — `references/visual-direction.md`; его файл не изменяется.

## Композиционный план

1. **Как эпоха меняет город?** Светлая типографическая афиша: крупный вопрос слева, фотография Дома Наркомфина справа, красное слово как главный акцент.
2. **Новая жизнь после потрясений.** Контрастный разворот: чёрное поле революции слева, светлое поле НЭПа справа. Крупные даты и нижняя красная полоса связывают восстановление с поиском нового быта.
3. **Башня для нового мира.** Документальная вертикальная фотография модели слева, заголовок и датировка справа. Отдельный явный статус «Не построена».
4. **Один конкурс — разные пути.** Альбомный разворот с неравными полями: проект Троцкого меньше слева, проект Весниных крупнее справа. Премии, авторы и статус неосуществлённого здания подписаны явно.
5. **Сначала задача — затем форма.** Три вопроса слева, крупная фотография Госпрома справа. Переход от проектов к анализу построенного здания.

## Рабочие константы

- 1920 × 1080; основные поля 88 px.
- Бумага `#F1EBDD`, чёрный `#171715`, красный `#C93728`, вторичный текст `#625D54`.
- Заголовки Oswald Bold; основной текст PT Sans Regular/Bold.
- Заголовки 96–156 px, тезисы 38–46 px, подписи 24–30 px.
- Повторяющиеся элементы: наборные номера, красная полоса, контраст крупной типографики и документального изображения.
- Фотографии показываются монохромно средствами Figma; исходники не изменяются. Пропорции изображений сохранены.
- Это одна система с тремя композиционными подачами: афиша, архитектурный альбом, журнальный монтаж. Следующий батч — после обсуждения.

## Результат и проверка

Созданы все пять слайдов: 56 текстовых объектов и пять изображений. Порядок подтверждён по дереву SLIDE_ROW; `getSlideGrid()` при повторном чтении возвращал пустой массив, поэтому проверка опирается на реальные узлы из `figma-nodes.json`.

Все пять слайдов просмотрены через рендеры Figma. Проверены подписи, историческая уместность, разнообразие композиций, сохранность изображений и авторской подписи на фотографии Госпрома. Автоматическая проверка не обнаружила выхода за границы или отсутствующих шрифтов; обнаруженные два пересечения текстовых рамок по 4 px на титульном исправлены заменой отрицательного межстрочного промежутка контейнера на нулевой. Подпись Госпрома выровнена по видимому краю фотографии.

После этих правок достигнут лимит Figma MCP тарифа Starter. Повторная автоматическая проверка после последней правки заблокирована лимитом. Сохранены локальные экспорты `slide-01.png` — `slide-03.png`; экспорт 04–05 также заблокирован лимитом. Все пять редактируемых слайдов и заметки уже находятся в Figma.

`build.js` — исходный сценарий создания геометрии в новом пустом Slides-файле; повторный запуск в текущем файле создаст дубликаты. Изображения загружаются отдельно в узлы, возвращённые сценарием, с режимом FIT. У изображений 01 и 05 установлена насыщенность −1 средствами Figma. Речь и источники для назначения `speakerNotes` — в `speaker-notes.json`.
