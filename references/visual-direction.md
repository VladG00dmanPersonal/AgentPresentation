# Visual direction

The deck should reference the visual language of Soviet Constructivism
without becoming a historical imitation.

I like:

- monumental typography;
- compositions built around diagonals;
- black-and-white photography;
- red used as an accent;
- geometric cropping;
- strong scale contrast;
- asymmetry;
- layouts where photographs become compositional elements.

I don't want:

- every slide to look like a propaganda poster;
- excessive decorative elements;
- modern corporate infographic aesthetics;
- gradients;
- rounded cards;
- generic startup presentation design.

The architecture itself should remain the focus.

Poster slides can be visually more aggressive than architecture slides.

The agent should propose the actual palette, fonts, grid, and visual motifs.
